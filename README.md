# Learn Well University – Course Management System (PoC)

A Course Management System for Learn Well University, comprising a .NET 9 Web API backend.

## Tech Stack

**Backend**
- **.NET 9**
- **Entity Framework Core 9**
- **Swagger (Open API)**

## API

### Swagger UI
[http://localhost:8080/swagger](http://localhost:8080/swagger) — interactive API docs.
### Import Postman Collection
- Open **Postman** and click **Import** button.
- Paste [http://localhost:8080/swagger/v1/swagger.json](http://localhost:8080/swagger/v1/swagger.json) into the **Import** dialog.
- Click **Import** button to import the collection.
